# 📊 Superstore Sales Dashboard

## 📌 Task 01 - SkillCraft Technology Internship

## 🎯 Objective
Visualize Total Sales, Profit by Category, and Sales Trends over time using Google Sheets.

## 📂 Dataset
- **Source:** Superstore Sales Dataset
- **Rows:** 9,800 records
- **Columns:** Order ID, Order Date, Ship Date, Segment, Region, Category, Sub-Category, Product Name, Sales

## 🛠️ Tools Used
- Google Sheets
- Pivot Tables
- Charts (Pie, Line, Bar)
- Conditional Formatting

## 📊 Dashboard Features
- ✅ Sales by Category (Pie Chart)
- ✅ Monthly Sales Trend (Line Chart)
- ✅ Sales by Region (Bar Chart)
- ✅ Conditional Formatting (Green-Yellow-Red color scale)

## 🔍 Key Insights
- **Technology** has highest sales (36.6%)
- **West** region leads in sales (₹7,10,219)
- Sales peak observed in certain months showing seasonal trends
